# 乔乔汉堡店

一款无需安装依赖的轻度休闲汉堡制作小游戏。

## 运行

直接用浏览器打开 `index.html` 即可游玩。也可以在此目录启动任意静态文件服务器。

## 已实现

- 顾客订单、排队和耐心值
- 按配方顺序制作、撤回和重做
- 金币、得分、连击与三星结算
- 5 个逐步增加难度的营业日
- 新食材和复杂配方逐步解锁
- 响应式手机与桌面布局
- 手机端单屏操作，无需上下滚动
- 操作、成功、失败、连击与结算音效，可一键静音
- 使用指定 MP3 作为循环背景音乐，开始营业后自动播放
- 金币本地保存
- 自动保存当前天数、订单进度、顾客、制作台和连击，刷新后可继续营业
- 第 5 天通关后进入难度持续提升的无限营业模式
- 顾客耐心较低时可花费订单售价的一半赠送礼物并恢复耐心
- 店铺升级系统：等待座位、高效厨房和人气招牌
- 订单显示明确售价，升级招牌可提高营业收入
